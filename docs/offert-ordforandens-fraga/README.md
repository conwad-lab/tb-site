# Ordförandens fråga — offertmall
Öppna `mall-sv.html` eller `mall-en.html` i en webbläsare och klicka i fälten; ersätt ☐ med ☑ för exakt ett valt svar.
Sätt leveransdatum till sju dagar före styrelsemötet och kontrollera att kundens fråga återges ordagrant.
Skriv ut till PDF i A4, med bakgrundsgrafik och utan webbläsarens sidhuvud eller sidfot; kontrollera att PDF:en har en sida.
Bifoga ditt eget avtal; pris och villkor finns i det.
