# Designutforskning: riktning B, Affischen

Skisser, inte produktion. Inget här publiceras (`docs/` är undantaget i `_config.yml`) och grenen ska inte bli en PR. En riktig ändring av sajten går som story via ORDER.md.

- `riktning-b-affischen.html`: landningssidan (svenska) i riktning B. Text, pris, bokningslänk och påståenden om grundaren är ordagrant från `sv/index.html`.
- `riktning-b-med-rattar.html`: samma sida med en panel för palett, typsnitt, &-tecknet, band, luft och rörelse.

Bakgrund: dagens sajt bär flera tecken på AI-genererad design (tunn serifrubrik med färgat slut, mono-etiketter över varje sektion, krämbakgrund med brons, numrerade kort, samma tona-in-effekt överallt).
